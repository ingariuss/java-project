# 🌸 LinguaRosa

Приложение для изучения **английского** и **иврита** с карточками. Розовое и милое 💗

Бэкенд написан на Java (встроенный HTTP-сервер, без фреймворков), интерфейс — HTML/CSS/JS в браузере.

## Что умеет

На главной выбираешь язык 🇬🇧 / 🇮🇱, потом тему (Приветствия, Семья, Еда, Цвета, Дом) и режим:

| Режим | Как работает |
|---|---|
| 🃏 **Карточки** | Нажми, чтобы перевернуть. Свайп вправо (или →) — «знаю», влево (или ←) — «ещё учу». В конце можно повторить только сложные |
| 🎯 **Викторина** | 10 вопросов, 4 варианта ответа; направление чередуется (слово → перевод и наоборот), есть серия 🔥 |
| ✍️ **Напиши слово** | Видишь перевод — вводишь слово. Для иврита подходит и иврит, и транскрипция русскими буквами. Есть подсказки 💡 |
| 💞 **Найди пару** | Соедини 6 слов с переводами на время |
| 📖 **Словарик** | Все слова с поиском, озвучкой 🔊 и отметкой «выучено» 💖 |

Прогресс («выучено») сохраняется в браузере. Озвучка — голосом браузера (для иврита нужен установленный голос he-IL).

## Как запустить

Нужны **Java 17+** и **Maven**.

```bash
mvn package
java -jar target/lingua-rosa.jar
```

Открой в браузере: http://localhost:8080 (другой порт: `PORT=9000 java -jar target/lingua-rosa.jar`).

## 📱 Открыть с телефона (GitHub Pages)

В папке `docs/` лежит готовая версия сайта, которой не нужен Java-сервер. Она обновляется сама — при `mvn package` или автоматически на GitHub после каждого изменения.

1. На GitHub: **Settings → Pages**.
2. **Source:** `Deploy from a branch`, **Branch:** нужная ветка, папка **`/docs`** → **Save**.
3. Через 1–2 минуты сайт откроется по адресу `https://<имя-пользователя>.github.io/java-project/`.

## Как добавить слова

**Прямо в приложении:** открой язык → розовая кнопка **＋ Добавить слово** (или круглая ＋ внизу экрана).
Заполни слово и перевод (транскрипция, тема и пример — по желанию) → **Добавить**.
Слово сразу появится во всех играх. Свои слова можно изменить или удалить в **Словарике** (кнопка ✏️).

Свои слова хранятся в браузере на том устройстве, где их добавили.

**Встроенные слова** (видны всем) лежат в `src/main/resources/cards/en.tsv` и `he.tsv`, по строке на карточку:
`тема | слово | транскрипция | перевод | пример`. После изменения GitHub сам пересоберёт сайт.

## Структура

```
src/main/java/app/lingua/
  App.java            — запуск
  LinguaServer.java   — HTTP-сервер: /api/languages, /api/cards?lang=en, статика
  CardRepository.java — загрузка карточек из TSV
  Card.java, Language.java, Json.java
src/main/resources/
  cards/              — словари
  static/             — интерфейс (index.html, styles.css, app.js)
src/test/java/        — тесты (mvn test)
```
